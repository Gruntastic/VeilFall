# Operation Dead Signal — G1 greybox
Build ID: VF-G1-20261003-A. UE 5.8.3 CL 58210709. G0 input accepted by the user on October 3, 2026; sensitivity remains a deferred tuning item at 0.24 degrees/count. This is a route/state prototype, not the final 20–30 minute combat mission.

Run from the VeilFallG0 project directory:
```powershell
./Scripts/G1.ps1 Bootstrap
./Scripts/G1.ps1 Host
./Scripts/G1.ps1 Join
./Scripts/G1.ps1 Editor
./Scripts/G1NetworkSmoke.ps1 -RttMs 100 -LossPercent 2
./Scripts/G1NetworkSmoke.ps1 -RttMs 200 -LossPercent 5
```
Bootstrap compiles, generates genuine assets, runs five engine tests, and packages Windows. G0 scripts and previous packages remain available. G1 map is /Game/DeadSignal/L_DeadSignal_G1; its own WorldSettings selects the G1 game mode. Route data asset: /Game/DeadSignal/DA_DeadSignal.

The route occupies a bounded 400 × 600 m footprint. Primitive houses, cover, stopped convoy silhouettes, facility walls and chamber structure establish locations. Roads guide the route; residential rear access and relay front/side access provide alternative approaches. There are no enemies or combat yet. Relay clearing and convoy recovery explicitly use greybox interaction stand-ins. No drivable vehicles.

Optional ledger at 74 / 128 and survey archive at 290 / 482 form the clue trail. Both fictional records persist as mission flags. Repeated or simultaneous action requests cannot advance twice; out-of-order actions cannot skip prerequisites. A coherent replicated record sends objective, outpost, clues, stash and revision to late joiners. Cosmetic markers derive their visibility from it. This does not implement future item inventories or recovery packs.

Establishment reveals resident and radio placeholders, enables the resupply marker and moves subsequent arrivals to the relay's four spawn points. Resupply currently reports availability; ammunition/medical supplies require G2. Players already in the session remain where they are. Death/respawn is not implemented.

UMG shows objective, distance/turn direction, clue/outpost/stash state and feedback; its current layout is native temporary greybox UI. Authored Blueprint layouts are deferred. E uses the existing owning-pawn interaction RPC, server eye trace, 300 cm range, line of sight and cadence limit. Clients never submit an action or save record through an RPC. Host console commands VFSave and VFLoad execute only on the local authoritative controller.

Host save: Saved/SaveGames/DeadSignal.vfs beside the running project's Saved directory (packaged: Windows/VeilFallG0/Saved). Accepted checkpoints autosave. Record schema 1 validates stable mission ID and objective/outpost/stash invariants. Schema 0 initializes absent clue bits; future schema is rejected. The binary envelope includes length and CRC. A flushed temporary file replaces the primary using Windows MoveFileExW with replace-existing and write-through. A previously valid primary is separately committed to .bak first. Corrupt primary falls back to backup; dual corruption protects the files from autosave overwrite. POSIX rename fallback exists but is NOT RUN. Power-loss fault injection and filesystem/hardware durability guarantees are NOT RUN.

Only mission evidence banking is represented in the stash at G1. Equipped loadout, field loot, recovery packs and permanent guest identity are deferred. Guests share the host world state for this session; no guest-owned campaign file is written.

For a new playthrough, first close the host and preserve/rename the entire Saved/SaveGames directory. Do not delete existing saves. Restart the host. Do not run two hosts against the same save directory.

Review one action at a time:
1. Launch G1 Host. Expected: HQ, first objective, crosshair.
2. Approach the briefing terminal and press E. Expected: objective changes to residential edge.
3. Follow the road and waypoint; inspect the rear alley ledger if desired.
4. Interact with survey, relay-clear, generator and establishment terminals in order. Expected: state advances 0/3 → 3/3; residents/radio appear.
5. Join another process. Expected: established outpost spawn and matching world state.
6. Recover convoy manifest, inspect facility and optional archive, then chamber.
7. Return to HQ and debrief. Expected: one banked evidence record, no repeat reward.
8. Exit/relaunch host. Expected: established outpost and completed record retained.
9. Record route legibility, travel time, objective discoverability and chamber reveal feedback before G2 content expansion.

Automated network diagnostics use explicit -G1Smoke server teleports to each real interaction node, with a non-interacting host and remote clients using the actual interaction RPC. Diagnostic save roots are isolated. They prove authored action/state/persistence behavior, not pedestrian traversal, human feel, visual quality or mission duration.

Diagnostic network port defaults to 7781, leaving the ordinary 7777 play port alone. Close previous host windows before launching the normal G1 Host command.
