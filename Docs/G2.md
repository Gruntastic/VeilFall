## Play and reproduce

From the project directory, run `./Scripts/G2.ps1 Bootstrap` to build the editor module, create genuine assets, run all eight engine tests, then cook/package Windows. The default engine argument is the actual installed `C:/Program Files/Epic Games/UE_5.8`. `./Scripts/G2.ps1 Editor` opens the G2 map. `./Scripts/G2.ps1 Host` launches its packaged listen server; `./Scripts/G2.ps1 Join` connects locally. For another LAN machine use the packaged executable with `<host-address>:7777`. Internet matchmaking remains outside scope.

WASD/mouse/Space/E retain accepted G1 controls and deferred sensitivity (0.24). LMB fires; RMB aims; R reloads; 1/2/3 select primary/secondary/sidearm; G uses medical; H uses ammunition kit; Enter respawns after death and a three-second wait. Hold position while a gadget or revive channels. At headquarters four labelled prototype benches swap carbine/marksman, cycle armor, restock, or explicitly down the interacting player for training. Three nearby targets represent light/medium/heavy armor. E resets a dead target. In co-op E on a downed teammate starts a three-second revive consuming the reviver's medical charge on completion. Downed self recovery takes five seconds; bleedout takes forty seconds. Established relay resupply now restocks combat players. G1 clearing/convoy interactions remain labelled stand-ins until AI encounters in G3.

## Authority and tuning

The owning pawn sends aim and a monotonically increasing shot sequence, never hit/damage/origin reports. Server validates possession, life state, ammunition limits, cadence, reload/use exclusions, direction normalization and aim alignment with authoritative control rotation. Hits are determined by server eye and muzzle visibility traces; intervening barrel cover blocks the shot. Shotgun spread is server seeded. Accepted shots spend one cartridge, including blocked shots. Conventional RPC ownership rejects calls from unrelated connections. Client input gives immediate cosmetic flash/recoil; authoritative ammo and feedback arrive through replication. Tracers are development cosmetics, not gameplay volumes.

Health is fixed at 100. Torso armor subtracts 4/10/16 damage for light/medium/heavy, reduced by weapon penetration (10/0/20/3). Head damage triples and limbs scale by 0.65, both bypass torso armor. Armor movement speeds are 600/510/420 cm/s. These are first-pass tunings, not final balance. Friendly fire is disabled. Prototype head/torso/limb boxes stand in for skeletal hit regions.

Reload transfers reserve only on server completion. Switching, damage, downing, death, and loss of possession interrupt pending actions. Revive validation continuously checks alive reviver, downed target, distance, line of sight, position drift, damage revision and possession. Racing completion rechecks target state before charging. Restock has no remote arbitrary refill RPC. Death retains equipped weapons, ammo, armor and gadget counts across local respawn. Field loot, recovery packs and persistent equipment records remain G3 work; host campaign saves still contain G1 mission/outpost/evidence only.

Weapon definitions are real primary data assets under `/Game/Combat` with stable IDs. `Content/Python/create_g2.py` uses the native default-spec function to create/update these assets and a cloned G2 map with training benches. Blender/art benchmarks remain deferred to G4; cube bodies/weapons/targets are explicit Unreal prototypes, not generated art or rigged assets.

## Evidence scope

`Docs/Logs/G2-Build.log`: successful editor compilation. `G2-Tests.log`: eight successful engine automation tests (five previous regressions and three combat fixtures). Combat tests cover aim/cadence/sequence/possession, blocked muzzle, region/armor arithmetic, ammo conservation/limits, interrupted reload and invalid slots, primary swap retention, interrupted revive/charges, self recovery, bleedout and retained loadout. Tests invoke private completion helpers to isolate state transitions; they do not replace separate-process or human timing tests.

`Scripts/G2NetworkSmoke.ps1` runs four packaged processes against explicit opt-in floating fixtures. It checks real owned combat RPCs, replicated target health, cartridge counts, timed reload, shotgun/pistol slots, ammunition kit and timed downed self recovery. The fixtures reposition actors and control aim; they are not physical input, route traversal, performance measurements, or a teammate-revive multiplayer test. Packet lag is half the requested nominal RTT on each endpoint; packet loss is per outgoing direction. Measured ping is not claimed.

Windows package, rendered launch/capture and network results are recorded separately after execution. Human G2 feel review, teammate revive in separate processes, combat late join/reconnect cleanup, animation/audio, and reference performance targets remain NOT RUN until evidence is recorded.
