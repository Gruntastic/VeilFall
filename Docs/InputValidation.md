# Input and movement verification
MouseSensitivity is explicitly 0.24 degrees per raw count; tunable on native character defaults. Legacy input scales are disabled. Engine SceneViewport.cpp subtracts screen-space Y delta, so upward mouse movement produces positive Unreal MouseY; positive controller pitch aims upward.
Enhanced Input mappings remain runtime-transient. W/S swizzle forward axis; A/D lateral; negate S/A; cumulative move action.
InputMovement engine test runs real EnhancedPlayerInput injection, existing mapping modifiers, bound delegates and CharacterMovement collision steps. Asserts four cardinal keys, diagonal callback, yaw-relative direction, look yaw/pitch and sensitivity, ground settlement, forward displacement, jump lift, release and landing.
The fixture marks a synthetic controller local, starts world actors, owns input processing and explicitly advances the engine movement component. It does not emulate Windows device events, viewport focus, UI focus changes or network movement correction. These are manual/packaged acceptance gaps.
Fixture failures are retained: PI macro naming collision corrected; viewport-free controller tick crash prevented; missing world BeginPlay/local designation corrected; synchronous world tick scheduling replaced with deterministic component stepping. These were test-fixture issues; no pass was inferred from source.
